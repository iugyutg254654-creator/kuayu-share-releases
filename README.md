## 主要功能

- **实时翻译与双语字幕**：展示原文和译文，选择目标语言，支持悬浮字幕。
- **会议录音与语音转文字**：保存会议录音，支持实时转写、会后转写，也可导入已有录音。
- **自动生成会议纪要**：整理简要总结、讨论重点、明确决议和任务安排；负责人、截止时间不明确时标注“待确认”。
- **会议纪要导出**：编辑会议名称、时间、地点、参会人员、主持人和记录人，导出 Word、TXT 或 Markdown，也可复制纪要。
- **分类保存与查找**：翻译记录与录音文档分开保管，支持搜索和回看。
- **自选 API 服务**：使用自己的 API Key，选择相应识别、翻译和纪要服务，不内置共享密钥。

## 怎么使用

1. 下载安装包，在设置的“API 入口”中填写自己的服务密钥。
2. 首页选择“实时翻译”或“会议录音”，选择语言与可用服务。
3. 结束后查看记录，生成会议纪要、编辑并导出文档。

本地中英文语音识别可离线使用；云端识别、翻译和纪要需要联网及对应服务，费用以服务商账单为准。GPT 语音识别与文字模型分别调用；DeepSeek 用于翻译和纪要，不提供本应用的语音识别。

## 平台与使用范围

- **Android 安卓**：适合线下收音与双语字幕。其他会议应用的音频能否采集受系统、音频用途和应用权限限制，不保证所有腾讯会议、Lark 通话都可内录。
- **Windows 电脑版**：支持电脑声音回录和麦克风采集，实际兼容性以设备和发布说明为准。
- **iOS 苹果版**：尚未提供。

录音和会议记录保存在本机；选择云端服务时，相关音频或文字会发送给所选服务商。录音前请告知参会人。AI 纪要请核对人名、任务和期限。
