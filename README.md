# 跨语

**听懂对话，记住重点。**

跨语是一款集实时翻译与会议录音于一体的助手，帮助你看懂双语字幕，把会议内容整理成清晰的纪要。

## 主要功能

- **实时翻译**：原文与译文同步展示，可选择目标语言，支持悬浮字幕。
- **会议录音**：保存录音，支持实时转写或会后转写，也可导入已有录音。
- **自动纪要**：整理简要总结、讨论重点、决议和任务安排，标注负责人及截止时间；未明确的信息保留待确认。
- **文档导出**：编辑会议信息，一键导出 Word、TXT 或 Markdown。
- **分类记录**：翻译记录与录音文档分开保存，方便查找和回看。

## 开始使用

安装后，可使用本地中英文语音识别；联网识别、翻译与纪要可在设置中配置自己的 GPT 或 DeepSeek 服务。
